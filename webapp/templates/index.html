KEY FINDINGS / 关键结论

  1. 01CBAM 是唯一在 val 与两个冷色域同步提升的单项（+3.8 / +7.3 / +14.9 pt），四域均值 80.5% 为全部 16 项实验最高，定为最终模型。
  2. 02白平衡+宽色相将暖色域 test_1 的灰尘误报 175 → 13（精度 46.2→90.8%）；WIoUv3 在同域 +16.5pt，r≥0.5 截断可修复其召回回退。
  3. 0360ep 长训改善基线跨域（t2 +14.2pt）却使注意力模型过拟合训练色域；RT-DETR-L（32.8M）val 84.3% 全场最高但暖色域崩至 14.6%。

CAVEATS / 已知注意事项

  1. 01test_1 仅含 particle 实例，其 defect 指标无统计意义，表中单独解读。
  2. 02本机 ultralytics 为 8.3.240，官方锁定 8.3.100；同系列数字可能有小幅版本差。
  3. 03RT-DETR-L 在 6GB 显存下以 batch=8 完成训练；若复现遇 OOM 可降 batch=4。
